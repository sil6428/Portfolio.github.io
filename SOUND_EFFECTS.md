# Sound-effect provenance

The portfolio does not include downloaded sound-effect recordings.

Every interface sound is synthesized at runtime in the visitor's browser using the Web Audio API. The tones are defined in `app/site-sfx.ts` and were created specifically for this portfolio.

The effects cover:

- Interface clicks
- Opening and closing object files
- Easter-egg discoveries
- Cat interactions
- The three-minute chess-set print completion

Visitors can turn interface sound effects off from the Soundtrack panel. The preference stays on their device.

The Spotify playlist link and any locally selected audio remain separate from the interface sound effects. No Spotify music or user-selected audio is bundled with the site.
